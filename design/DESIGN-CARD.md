# BlankRun 设计卡

**给谁 / 解决什么**：夜里让 AI agent（Claude Code、Codex、本地模型等）和编译、下载继续跑的人。要让屏幕和灯全黑，同时电脑不睡，早上或按下快捷键时再亮。
**每屏唯一主任务**：弹出面板是「立即息屏」；设置页是「改对一项」；息屏态是「知道怎么唤醒」；首次引导是「打开还没开的那项权限」。

## 色（6 个命名色，黑白灰为主）
| 名 | 值 | 用在 |
|---|---|---|
| 纸 paper | `#FFFFFF`，窗口底 `#F5F5F4`（Win `#F3F3F3`） | 背景 |
| 墨 ink | `#1C1C1E`，次级 `#6B6B70`，弱 `#9C9CA1` | 文字；开关打开时的填充色 |
| 线 line | `#E5E5E7` | 分隔线、控件描边 |
| 熄屏黑 blank | `#111113` | **主操作**：「立即息屏」按钮本身就是一块熄掉的屏幕 |
| 待机琥珀 standby | `#E39B2D` | **唯一强调色**：只表示「息屏中 / 倒计时中 / 计划已开」这类关键状态 |
| 成功 / 危险 | `#2F8F4E` / `#C4442F` | 只在诊断页的权限和能力状态里出现 |

开关打开时用墨色，不用系统蓝。这样整个界面只有一处会有颜色，就是那颗琥珀灯。

## 深色模式（跟随系统）
- 底色降到近黑的中性灰：桌面 `#0C0C0D`、窗口 `#1E1E20`、侧栏 `#18181A`；控件和分组比窗口亮一级（`#29292C` / `#242426`）；字 `#ECECEE / #A1A1A6 / #6E6E73`；线 `#323235`。
- 「立即息屏」仍然是一块**比周围更黑**的屏幕（`#050506`），加一圈 9% 白的细边，才看得出边界。
- 开关、勾选、单选的「开」反转成浅墨色填充 + 深色滑块，依旧不用系统蓝；次要主按钮（如「打开系统设置」）也反转为浅色。
- 琥珀色略提亮到 `#E8A33B`，保证在暗底上的辨识度，用途不变：只表示关键状态。去掉控件的浅色投影，避免暗底上发灰。

## 字
- 正文和标题都用系统字体：Mac 是 `-apple-system / PingFang SC`，Windows 是 `Segoe UI Variable / Microsoft YaHei UI`。体积为 0，观感原生，不另外打包 Inter 这类网页字体。
- **数字和快捷键用等宽字体**：`SF Mono / Cascadia Mono`。时间（23:30 → 07:30）、倒计时（4:32）、像素和毫秒值都用 tabular 数字，像一块时钟。
- 只分 3 级字号：标题 20/600，正文 13/400，辅助 11–12/400 弱色。

## 布局
- 弹出面板：从上到下，先看到黑色主按钮，然后是今晚的计划，最后是唤醒方式这些小字。
- 设置页：左边是分区，右边是单层分组表单。每行左边写「这是什么」，右边放控件，下面一行写「为什么 / 会怎样」。不用卡片套卡片。
- 息屏态：整屏纯黑，只在中心放一行 40% 白的提示，3 秒后淡出。
- 视线路径：主操作 → 状态（琥珀） → 细节 → 脚注。

## 调性
克制、可信、安静，像深夜关掉的显示器。

## 记忆点（只留这一处）
**显示器待机灯**：主按钮是一块黑色面板，右下角有一颗琥珀色小灯，就像显示器关掉后那颗待机灯。倒计时、息屏中和计划开启这三种状态都用同一颗灯表示，其他地方一律不用颜色。

## 自检（AI 味黑名单）
不用紫蓝渐变，不全站 Inter，不用大圆角卡片，不卡片套卡片，不用 emoji 图标，不用玻璃拟态，不用装饰网格或噪点。图标只用 1.5px 线条 SVG，能不用就不用。
