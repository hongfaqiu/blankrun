功能Features

真关屏，不睡眠Real display off, no sleep
macOS 用 IOPMAssertion 阻止睡眠，Windows 用 SetThreadExecutionState；关的是显示器电源，不是盖一层黑图。MacBook 内建屏像合盖一样断开（面板断电），唤醒后接回。IOPMAssertion on macOS and SetThreadExecutionState on Windows block sleep. The display is actually powered down, not covered with a black image. On a MacBook, the built-in display is disconnected the way closing the lid does it (panel powered down) and reconnected on wake.
逐台断电Per-display power-off
Windows 上支持 DDC/CI 的显示器可以单独断电，其余盖黑色遮罩；每台可选「自动 / 仅遮罩 / 断电」。不响应断电指令的显示器会被自动识别，改用遮罩。远程软件的虚拟显示器不遮、不断电。On Windows, displays with DDC/CI can be powered off one by one; the rest get a black overlay. Each display can be set to Automatic, Overlay only or Power off. Displays that ignore power-off commands are detected and switched to the overlay. Virtual displays from remote tools are left alone.
键鼠照常用（Mac mini 模式）Keep using keyboard & mouse (Mac mini mode)
配合「只关所选」，只关 MacBook 内建屏，外接屏照常亮着，本机键盘、鼠标、触控板照常用，光标不会跑进关掉的屏。按住唤醒快捷键、紧急键、菜单栏或计划结束才恢复。Windows 上同样可用。With “Selected only”, turn off just the MacBook’s built-in screen and keep working on the external display with the local keyboard, mouse and trackpad; the cursor stays off the dark screen. Holding the wake shortcut, the emergency key, the menu bar or the schedule end bring it back. Works on Windows too.
放行远程控制Allow remote control
开启后，向日葵、ToDesk、Parsec 等远程软件的键鼠操作直接放行，不会唤醒本机屏幕；已断电的显示器撤下遮罩，远程画面照常可见。远程桌面（RDP）会话中不息屏。When on, input from Sunlogin, ToDesk, Parsec and similar tools passes through without waking the local screens. Displays that are powered off drop their overlay so the remote view still shows the desktop. BlankRun doesn't blank inside a Remote Desktop (RDP) session.
防误触唤醒No accidental wake
息屏期间拦截键鼠输入。唤醒方式可选：任意键、按住快捷键、移动鼠标、点击、输入密码、只在定时结束时。另有一个随时可用的紧急恢复键。Input is swallowed while blank. Wake by any key, holding a hotkey, mouse move, click, password, or only when the schedule ends. An emergency restore hotkey always works.
定时计划Schedule
比如每天 23:30 → 07:30，支持跨午夜，可以只跳过今晚。For example 23:30 → 07:30 daily. Works across midnight, and you can skip just tonight.
键盘背光Keyboard backlight
macOS 上和屏幕一起关掉。用的是系统私有接口，启动时先探测，不可用就跳过，不影响其他功能。Turned off together with the screen on macOS. It uses a private API that is probed at runtime and skipped when unavailable.
Windows 待机兜底Modern Standby fallback
有些新款 Windows 笔记本一关屏就进低功耗待机，后台任务会被挂起。检测到这类机器时，改用全黑遮罩。Some Windows laptops drop into Modern Standby when the display turns off, which suspends background jobs. BlankRun detects this and uses a black overlay instead.
小，而且只在本地Small and local
基于 Tauri 2，用系统自带 WebView，前端零依赖。安装包只有几 MB。除了每天一次检查更新（可关），不联网、不上传；更新包有签名校验，下载失败会自动重试。开源（MIT）。Built on Tauri 2 with the system WebView and a zero-dependency UI. Installers are a few MB. No telemetry; the only network use is a daily update check you can turn off. Updates are signed and downloads retry on failure. MIT licensed.

首次打开First launch

macOS
把黑着跑拖进「应用程序」，按住 Control 点它选「打开」（或在终端运行 xattr -dr com.apple.quarantine /Applications/BlankRun.app）。然后在「系统设置 › 隐私与安全性」里允许「辅助功能」和「输入监控」，用来拦下误触；每次更新后需要重新允许一次。Drag BlankRun to Applications, then Control-click it and choose Open (or run xattr -dr com.apple.quarantine /Applications/BlankRun.app). Then allow Accessibility and Input Monitoring in System Settings › Privacy & Security so it can block accidental touches. Allow them again after each update.
Windows
运行安装程序。如果出现「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。Run the installer. If SmartScreen says "Windows protected your PC", click More info → Run anyway.
