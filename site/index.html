功能Features

下面的功能代码都写好了，还在等真机验证。All of this is written and waiting for real-hardware testing.

真关屏，不睡眠Real display off, no sleep
macOS 用 IOPMAssertion 阻止睡眠，Windows 用 SetThreadExecutionState；关的是显示器电源，不是盖一层黑图。IOPMAssertion on macOS and SetThreadExecutionState on Windows block sleep. The display is actually powered down, not covered with a black image.
防误触唤醒No accidental wake
息屏期间拦截键鼠输入。唤醒方式可选：任意键、按住快捷键、移动鼠标、点击、输入密码、只在定时结束时。另有一个随时可用的紧急恢复键。Input is swallowed while blank. Wake by any key, holding a hotkey, mouse move, click, password, or only when the schedule ends. An emergency restore hotkey always works.
定时计划Schedule
比如每天 23:30 → 07:30，支持跨午夜，可以只跳过今晚。For example 23:30 → 07:30 daily. Works across midnight, and you can skip just tonight.
键盘背光Keyboard backlight
macOS 上和屏幕一起关掉。用的是系统私有接口，启动时先探测，不可用就跳过，不影响其他功能。Turned off together with the screen on macOS. It uses a private API that is probed at runtime and skipped when unavailable.
Windows 待机兜底Modern Standby fallback
有些新款 Windows 笔记本一关屏就进低功耗待机，后台任务会被挂起。检测到这类机器时，改用全黑遮罩。Some Windows laptops drop into Modern Standby when the display turns off, which suspends background jobs. BlankRun detects this and uses a black overlay instead.
小，而且只在本地Small and local
基于 Tauri 2，用系统自带 WebView，前端零依赖。安装包只有 1–3 MB。不联网、不上传，开源（MIT）。Built on Tauri 2 with the system WebView and a zero-dependency UI. Installers are 1–3 MB. No network, no telemetry, MIT licensed.

之后的版本：外接显示器断电（DDC/CI）、RGB 灯、开机启动、全局快捷键、开始前提醒、全屏视频时跳过。Later: external monitor power via DDC/CI, RGB lighting, launch at login, global hotkey, pre-start reminder, skip during fullscreen video.
